# Banco de Dados Restaurante

Projeto de estudo de SQL (MySQL) usando um banco de dados de restaurante, com tabelas de funcionários, clientes, produtos, pedidos e informações dos produtos.

## Estrutura do banco

- `funcionarios`
- `clientes`
- `produtos`
- `pedidos`
- `info_produtos`

## Arquivos

| Arquivo | Conteúdo |
|---|---|
| `01_definicao.sql` | Criação do banco e das tabelas |
| `02_manipulacao.sql` | Inserção, atualização e exclusão de dados |
| `03_consulta.sql` | Consultas básicas, ordenação e limite |
| `04_condicional.sql` | Filtros, `LIKE`, `IN`, `BETWEEN`, `NULL` e `CASE` |
| `05_agregacao.sql` | `COUNT`, `AVG`, `MIN`, `MAX`, `GROUP BY` e `HAVING` |
| `06_multiplas_tabelas.sql` | `INNER JOIN` e `LEFT JOIN` |
| `07_consultas_avancadas.sql` | Views, funções e `EXPLAIN` |

## Como usar

1. Abra o MySQL (Workbench ou terminal).
2. Execute os arquivos na ordem numérica, começando pelo `01_definicao.sql`.

## Tecnologias

- MySQL
